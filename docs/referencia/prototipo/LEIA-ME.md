# Protótipo: arquivos-fonte das telas

Cada arquivo .dc.html é uma tela do protótipo aprovado no Claude Design.
São HTML com estilos inline: use como referência de layout, espaçamento, cores, textos e estados.
Não são código de produção e não rodam fora do editor (dependem de um runtime próprio).

## Imagens

A pasta `imagens` tem uma captura de cada tela (`tela-<número>.png`), tirada do
protótipo visual exportado pelo Claude Design. O HTML exportado (8,3 MB, com as
fontes embutidas) não é versionado; as capturas bastam como referência.
